Entry for [The Funniest Sick Day Excuse](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) competition on make.fun: a program that writes a single one-line sick-day excuse, judged head to head on whether it is half believable, fresh, and lands its laugh before the last word.

## The line

A sneeze does the believable sick-day work up front, then the excuse escalates: the soul clocked out early, and HR itself delivers the closing twist — no working unsupervised. No fever, dog, or dead-grandmother clichés, and no wasted words.

## Layout

- `main.py` — entrypoint run by the grader; writes the single excuse line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The text is 123 characters, inside the 1–200 gate.
